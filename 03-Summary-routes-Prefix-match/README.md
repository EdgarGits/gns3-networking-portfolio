# Laboratory 03: Summary routes

##  Description
Laboratory on **GNS3** to learn about **Summary routes** on a router. Routers store fewer entries, saving memory and CPU cycles, when there are overlapping routes, the longest prefix will be selected.

##  Key commands to make the configuration
Creating the routes:

```text
ip route
```

##  Key commands to check the configuration
Checking the routes:
```text
show ip route
show ip interface brief
ping
trace
